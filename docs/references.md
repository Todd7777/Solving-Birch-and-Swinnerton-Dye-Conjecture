# References

Only works actually used in these notes are listed. Journal data are given where I am confident of them;
the arXiv identifier or year is given otherwise. (Compiled from memory and a few checked sources; if you
find a bibliographic slip, the mathematics quoted was checked against the stated hypotheses, not the page numbers.)
